# 台北晶華酒店 3D 六角群島導覽

## 功能
- 以台北晶華酒店為中央主島，周圍配置 20 座等尺寸六角形觀光景點島。
- 微縮玩具模型城市風格、柔和日光、海面波紋、緩慢飄動雲朵與熱氣球。
- 右下角可切換早、午、晚三種環境光線。
- 左上角即時顯示本機日期與時間。
- 點擊島嶼後鏡頭平滑聚焦，右側滑出景點資訊卡，含官方資訊連結、Google 地圖及捷運建議。
- 點擊發光虛線可查看兩個景點的旅遊串聯建議。連線僅代表導覽建議，不表示官方合作關係。
- 飯店主島提供客房服務、餐廳、SPA及飯店服務設施介紹。
- 飯店員工主角可用桌面目的地選單移動，手機可用左下角虛擬搖桿自由移動；另有旅客人物漫遊動畫。
- 支援滑鼠拖曳、手機觸控旋轉及縮放。

## 部署
將 `index.html` 與 `hotel-island-data.json` 放在 GitHub Pages 專案根目錄。開啟 GitHub Pages 後使用網站網址瀏覽。網頁使用 Three.js 0.128.0 CDN，因此初次載入需有網路連線。

## 注意
本專案為前端展示網站，不含登入、會員或後端管理功能。景點官方連結與交通資訊應在正式對外使用前再次核對最新公告；捷運建議不代表即時路線規劃。

# 台北晶華酒店 3D 城市導覽島

## 檔案
- `index.html`：新版 3D 互動導覽首頁
- `hotel-island-data.json`：飯店、20 個景點、官方資訊連結、地圖連結與捷運建議
- `gemini-hotel-island.json`：相容用資料副本
- `hotel_island_3d.html`：原始版本備份
- `gemini-hotel-island.html`：原始一般版頁面備份

## 使用方式
請將整個資料夾部署到 GitHub Pages，或使用本機 HTTP 伺服器開啟。新版首頁會讀取同資料夾的 `hotel-island-data.json`，不建議直接以 `file://` 開啟。

## 互動功能
- 飯店主建築固定在 3D 場景中心。
- 20 個景點可點擊查看介紹、官方資訊入口、Google 地圖與捷運搭乘建議。
- 飯店中心可查看客房、餐廳、SPA、飯店服務設施資訊。
- 多位旅客人物會在景點之間漫遊。
- 飯店員工主角有醒目標記，可由右側下拉選擇目的地並控制移動，也可返回飯店。

## 資料與安全說明
- 景點文字以使用者提供內容為基礎，並做精簡整理；官方來源網址優先使用場館官方網站，未提供獨立官方頁面的地點連至臺北旅遊網官方景點入口。
- Google 地圖使用地名搜尋連結；捷運資訊為建議路線，出發前請核對即時站務、公車及步行資訊。
- 3D 引擎 Three.js 與 OrbitControls 仍由 jsDelivr CDN 載入，需網路連線；正式公開前可再改成本機託管並設定版本完整性驗證。
- 此版本未包含管理員登入或 Google 表單後台；一般旅客頁面不提供管理入口。
- 3D 場景位置是依座標製作的示意配置，非測量級導航底圖；實際導航請使用每個景點的 Google 地圖連結。
